منهج الأمن السيبراني

ابدأ بالمفاهيم التي تفسّر كيف تعمل الأنظمة، ثم انتقل إلى الممارسة داخل مختبرات آمنة ومصرح بها.

الترتيب المقترح مرن: خصص وقتًا للتطبيق القانوني، ودوّن ما تتعلمه، ولا تنتقل إلى اختبار أي نظام قبل تحديد النطاق والحصول على موافقة مكتوبة.

مقدمة في الأمن السيبراني

مبادئ السرية والسلامة والتوافر، ونموذج التهديد، وأدوار الدفاع.

مبتدئ

أنواع الهاكرز وأخلاقيات المهنة

الفروق بين الاختبار المصرح به والنشاط الإجرامي، وحدود مسؤولية المختبر.

مبتدئ

أساسيات الشبكات

عناوين IP وDNS وTCP/IP والمنافذ، وكيفية قراءة اتصال بسيط.

مبتدئ

Linux والأوامر الأساسية

تنقل الملفات والصلاحيات والعمليات والبحث في السجلات من الطرفية.

مبتدئ

تثبيت Kali Linux على VirtualBox

جهّز آلة افتراضية معزولة، واضبط الشبكة على وضع آمن، وخذ لقطة استعادة قبل التجارب.

مبتدئ

Python للممارسين الأمنيين

المتغيرات والملفات وطلبات HTTP وتحليل بيانات تملكها أو صُنعت للتدريب.

متوسط

Bash Scripting

متوسط

متوسط

OSINT المسؤول

متوسط

تحديد النطاق وجمع المعلومات

اتفاق مكتوب، أصول مسموح بها، أوقات الاختبار، وخطة تواصل واضحة.

متقدم

الفحص والتعداد

تحقق محدود داخل مختبر تملكه، وسجّل الإعدادات والنتائج دون تجاوز النطاق.

متقدم

تحليل الثغرات

متقدم

متقدم

ما بعد التحقق والتعافي

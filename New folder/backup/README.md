# بيشوي سايبر سكيورتي

موقع تعليمي ثابت باللغة العربية لدراسة أساسيات الأمن السيبراني والاختبار الأخلاقي. مبني باستخدام HTML وCSS وJavaScript فقط، دون خادم أو حزم بناء.

## تشغيل الموقع

افتح `index.html` مباشرة في المتصفح، أو استخدم إضافة Live Server في VS Code ثم اختر **Open with Live Server**. بعض خصائص الحافظة قد تتطلب سياقًا آمنًا مثل `localhost`.

## الصفحات

- `index.html`: الرئيسية ومسارات التعلم.
- `curriculum.html`: المنهج التفاعلي بأربع مراحل.
- `hacking.html`: مرجع قابل للبحث للفئات والأمثلة التعليمية.
- `tools.html`: الأدوات وروابطها الرسمية.
- `resources.html`: مختبرات ومراجع وشهادات.
- `about.html`, `contact.html`, `disclaimer.html`: معلومات الموقع والتواصل وإخلاء المسؤولية.
- `css/style.css`: التصميم المتجاوب ودعم RTL والحركة المخففة.
- `js/main.js`: القائمة والتأثيرات والبحث والنسخ وAccordion.
- `js/hacking-data.js`: بيانات صفحة المرجع منفصلة عن HTML.

## التخصيص

عدّل `window.hackingCategories` في `js/hacking-data.js` لإضافة فئة أو عنصر. الحقول هي `id`, `title`, `icon`, و`items`؛ ولكل عنصر `name`, `description`, `code`, `level`, `tone`, و`example`.

## الاستخدام المسؤول

المحتوى للتعليم والتوعية فقط. نفّذ الاختبارات حصريًا على أنظمة تملكها أو لديك تصريح مكتوب لاختبارها، وراجع النطاق والقوانين المحلية. بعض الأوامر والأدوات مزدوجة الاستخدام؛ راجع تنبيه صفحة الاختراق وإخلاء المسؤولية.

## ملاحظات خارجية

تستخدم الصفحة خطوط Google Fonts وأيقونات Font Awesome عبر CDN؛ عند عدم توفر الإنترنت تعمل الصفحات مع الخطوط البديلة، وقد لا تظهر الأيقونات.
